Instructions for the laboratory work "Programming bots for the game of Bashe"

In this laboratory work, we will get acquainted with the simulation environment for the Bachet's game and the software agents that will play it. We will create our own software agents and arrange tournaments between them.

Step 1
Open the Lab1 folder. Launch the index.html file in a browser and open the browser console.
At the start of the main.js script, a game world for Bashet's game is created, in which players are allowed to take 1, 2, or 3 stones. The player who takes the last stone wins.

Let's introduce two bots into this world and have them play one game.

Two types of bots are provided:

BachetBot1 can only take 1 stone per turn.

BachetBotRandom always determines its move randomly, choosing a number from 1 to 3.

Enter the following command into the console:
window.world.bots = [new BachetBot1("B1"), new BachetBotRandom("RND")]

This will create two bots of the specified types with the names B1 and RND.

Now, to run a single game between these bots, enter the command:
window.world.startGame(true)

You will see the turn-by-turn result of the game between these two bots.

Step 2
Now, let's run a tournament between these two types of bots where they will play 1000 games, each starting with a random number of stones.
window.world.startTournamentBetweenBots([new BachetBot1("B1"), new BachetBotRandom("RND")], 1000, 2, false)

You will see the tournament results in the console. Take note of the average number of games each bot wins.

Step 3
Now, let's develop a new bot that always takes 2 stones, no matter what. The code for this bot should be written in the bots.js module.
Use the bot that takes 1 stone as a template. Name the class for this new bot BachetBot2.

Run a tournament for all three bots, where each bot will play 1000 games against every other bot. This is done with the following command in the console:
window.world.startTournamentBetweenBots([new BachetBot1("B1"), new BachetBotRandom("RND"), new BachetBot2("B2")], 1000, 2, false)

Record the results of the bots in this tournament.

Step 4

Let's create an improved version of BachetBot2. Its current version will try to take 2 stones even when there is only 1 stone left in the pile. This often results in a loss due to violating the game rules.
Develop a bot named BachetBot2Smart. Give it the following behavior: if there is exactly 1 stone in the pile, it will take that 1 stone; in all other cases, it will take 2 stones.

The bot's behavior is controlled by the makeMoveForSituation(gameDataOb) function.
The gameDataOb object contains the N parameter, which is the current number of stones.

Therefore, the function for the BachetBot2Smart bot will look like this:

makeMoveForSituation(gameDataOb){
    if (gameDataOb.N==1){
        return {n:1}
    }else{
        return {n:2}
    }
}

After adding the BachetBot2Smart bot to the bots.js file, run a tournament with all four types of bots by executing this command in the console:
window.world.startTournamentBetweenBots([new BachetBot1("B1"), new BachetBotRandom("RND"), new BachetBot2("B2"), new BachetBot2Smart("B2Smart")], 1000, 2, false)

Step 5
Let's make an improved version of the bot that takes a random number of stones. This bot also frequently loses for violating the rules because, by choosing a move randomly, it might try to take more stones from the pile than are available (the game counts an illegal move as a loss).

Create a bot named BachetBotRandomSmart that will make a random move if there are 3 or more stones. If there are 2 stones on the table, it will randomly take 1 or 2, and if only 1 stone remains, it will simply take it.

After adding this bot, run a tournament with all five types of bots. Record the final ranking of the bots.

Step 6
Now, add a bot that implements the perfect strategy for this version of the game of Bashe. As we found out in the lecture, the perfect strategy is to leave for an opponent a quantity of stones on the pile, which is divisible by 4. After running a tournament, confirm that it soundly defeats all other bots.

Step 7
Create a bot that plays only slightly weaker than the perfect bot but is stronger than all the other five bots.

Individual task: Creating bots for a tournament with the rules 1, 3, 4
In the lecture, we discussed an alternative version of the rules for the game of Bashe, where you can only take 1, 3, or 4 stones from the pile, and the player who makes the last move wins.

For these rules, we will organize a tournament among all the bots developed by the students.

To test how your bot will behave under these new rules, go to the main.js file, comment out the line:
window.world = new BachetWorld();
and uncomment the line:
window.world = new UniversalBachetWorld([1,3,4],true);

This will create a game world where the allowed moves are 1, 3, and 4, and the player who takes the last stone wins.

Test how the bots you created for the (1, 2, 3) rules perform here.

Develop a bot that plays better under these new rules.
