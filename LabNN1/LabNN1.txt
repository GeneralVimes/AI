Laboratory work on neural network training №1
It is best to perform this work in the Chrome browser.

Step 1.
The file main.js contains the code for building and training a neural network
that compares two numbers.
Run index.html.
Ensure that the number displayed in the console is greater than 0.9.
This is the performance (accuracy) of the trained network.
Record this value.

Check how the trained network recognizes a specific pair of numbers.
To do this, enter the following into the console:
window.network.calculateOutsForInputs([5,10])
window.network.getOutputs()

You will see what the activation of the output layer of the neural network is
for these input numbers.

Come up with 3 more examples of input data yourself and try them. Record the
network activation for each of them.

Step 2.
Let's examine the network in detail.
Provide the numbers 6 and 7 as input:
window.network.calculateOutsForInputs([6,7])

Now let's export the entire network.
To do this, enter the command:
window.network.export2Text()

Right-click on the outputted text — Copy String Content — and paste the data
from the buffer into Excel.
In Excel, you might need to replace dots with commas (depending on your regional
settings) for better formatting.

Step 3.
You can see that the values of the output neurons are not exactly equal to 0
and 1.
Let's "fine-tune" the network a little bit.
Tell the network that for these specific input data, the ideal activation of the
output layer should be the array [0,1]:
window.network.calculateErrors([0,1])

Now, let the network perform an adjustment of the weight coefficients with a
learning rate (coefficient) of 0.25 (to make the adjustment effect more
obvious):
window.network.adjustParams(0.25)

Provide the pair of numbers 6 and 7 as input again and examine the network in
detail:
window.network.calculateOutsForInputs([6,7])
window.network.export2Text()

This time, paste the network data onto a different Excel sheet.

Compare how the network's output changed after one training step and how its
internal weight coefficients were modified.

Step 4.
Let's investigate in detail how the activation of the output neurons changes if
we vary the numbers provided as input.
We will feed the network a pair of numbers [6, x], where the number x runs
from 0 to 12 with a step of 0.1.

var ar=[]
for (var x=0; x<=12; x+=0.1){
    window.network.calculateOutsForInputs([6,x])
    var out_ar = window.network.getOutputs()
    out_ar.splice(0,0,x)
    ar.push(out_ar)
}
console.table(ar)

You will get a table where the first column is the value of x, followed by the
activations of the first and second neurons for that given x.
Build the neuron activation graphs in Excel.

Step 5.
Let's experiment with how the internal structure of the network affects its
ability to solve the problem.
Make a change to the network:
Change the number of neurons in the internal (hidden) layer, or the number of
internal layers, or the activation function (add "relu", "leakyrelu", or
"softmax" as the second parameter in createLayer).
Repeat steps 1-4 for this new configuration.

During the lab defense, demonstrate your records and tables, and show how the
change in the network structure affected its ability to solve the task.
