Крок 1.  
Файл main.js містить код побудови та навчання нейромережі, що порівнює два числа
Запустить index.html 
Переконайтеся, що число виведене в консолі є більшим за 0.9
Це результативність навченої мережі
Запишіть його

Перевірте на якісь парі чисел, як навчена мережа ї розпізнає
Для цього введіть у консоль 
window.network.calculateOutsForInputs([5,10])
window.network.getOutputs()

Ви побачите, якою буде активація вихідного шару нейромережі для вхідних чисел

Придумайте самі та спробуйте ще 3 приклади для вхідних даних. Запишіть для них активацію мережі

Крок 2.
Роздивимося мережу у деталях. 
Подайте на вхід числа 6 та 7:
window.network.calculateOutsForInputs([6,7])

Тепер виведемо мережу цілком
Для цього введіть команду 
window.network.export2Text()

Правою кнопкою по виведеному тексту - Copy String Content - і вставте дані з буфера у Excel
У Excel може знадобитися ще замінити точки на коми для кращого форматування

Крок 3.
Ви бачите, що значення вихідних нейронів не дорівнюють точно 0 та 1
Трошки підучимо мережу.
Вкажіть мережі, що для цих вхідних даних ідеальною активацієї вихідногшо слоя буде масив [0,1]
window.network.calculateErrors([0,1])

Тепер нехай мережа зробить підлаштовування вагових коефіцієнтів із коефіцієнтом 0.25 (щоб ефект підлаштовування був явніший)
window.network.adjustParams(0.25)

Знов подамо на вхід пару чисел 6 та 7 та роздивимося мережу в деталях

window.network.calculateOutsForInputs([6,7])
window.network.export2Text()

Цього разу вставте мережу на інший лист Excel

Порівняйте, як змінився вихід мережі після одного кроку навчання та як змінилися її внутрішні вагові коефіцієнти

Крок 4.
Дослідимо в деталях, як буде мінятися активація вихідних нейронів, якщо ми будемо міняти числа, що подаються на вхід
Будемо подавати на вхід пару чисел [6, x], де число х пробігатиме від 0 до 12 з кроком 0.1

var ar=[]
for (var x=0; x<=12; x+=0.1){
    window.network.calculateOutsForInputs([6,x])
    var out_ar = window.network.getOutputs()
    out_ar.splice(0,0,x)
    ar.push(out_ar)
}
console.table(ar)

Ви отримаєте таблицу, перша колонка якої - значеня х, а далі йдуть активації першого та другого нейронів для даного х
Побудуйте графіки активації нейронів в Excel
