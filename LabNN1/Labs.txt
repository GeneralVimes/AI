Neural Network Research
The neural network provided in NeuroNets/js/main.js learns to determine the quadrant of a coordinate plane based on a pair of coordinates (x, y).

Task 1: Circle Geometry
Create a neural network with 3 input neurons and 2 output neurons.
Inputs: A pair of point coordinates (x, y) and a circle radius r (centered at the origin).
Outputs: The first neuron should activate if the point is inside the circle; the second if it is outside.

Task 2: Proximity Detection
Create a neural network with 5 input neurons and 2 output neurons.
Inputs: Coordinates of the first point (x1, y1), coordinates of the second point (x2, y2), and a distance d.
Outputs: The first neuron should activate if the points are closer than distance d; the second if they are further apart.
Experiment:
Test how the trained network behaves. Provide an input array [1, 2, -2, -3, d], where d varies from 4 to 6 with a step of 0.1. Determine the activation levels for each d and build a graph.
