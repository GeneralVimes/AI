Laboratory work on neural network training №2

Let's train a neural network to compare numbers using a more complex algorithm.
Let's make it also determine the case when the numbers are approximately equal
to each other.

In this case, there will be 3 neurons in the output layer:

1.  The first will activate if the first number exceeds the second by more
    than 5%.
2.  The second neuron will activate if the first number is within a 5% deviation
    from the second.
3.  And the third neuron will activate if the first number is less than the
    second, taking into account the 5% margin of error.

What needs to be modified in the training script for this?

Firstly, you need to create 3 output neurons in the network.

Next, we modify the function that determines the correct network response during
training. It should return 0 if the first number is greater than the second
increased by 5%; return 2 if the first number is less than the second decreased
by 5%; and return 1 in all other cases. Here is what should be inside it:

let x = input_arr[0]
let y = input_arr[1]
if (x > y + 0.05 * Math.abs(y)) {
    return 0
} else {
    if (x < y - 0.05 * Math.abs(y)) {
        return 2
    } else {
        return 1
    }			
}

Please note that to determine the boundaries, we take the absolute value
(modulus) of the number (Math.abs(y)) so that the code works for negative
numbers as well.

Changes are also needed in the generation of the training sample. We can no
longer take both input numbers randomly, and here is why: in the training
sample, we need to equally represent all situations the network will encounter.
If we generate numbers purely randomly, the case of approximate equality
(within 5%) will occur very rarely.

Therefore, we will perform the generation of training data as follows:

1.  Generate the second number randomly.
2.  Generate the first number within a 5% deviation from the first.
3.  Next, in 33% of cases, regenerate the first number so that it is clearly
    smaller than the second.
4.  In another 33% of cases, regenerate the first number so that it is clearly
    larger than the second.

let y = Math.random() * 20 - 10
let x = y + Math.abs(y) * (0.05 - 0.1 * Math.random())
let rnd = Math.random()
if (rnd < 0.33) {
    x = y - Math.abs(y) * 0.05 - Math.random() * 20
}
if (rnd > 0.67) {
    x = y + Math.abs(y) * 0.05 + Math.random() * 20
}

We will do the same when generating the test data. The only difference is that
we will take the range for them from -1000 to 1000 (to check how the network
learned to generalize the concept of comparison).

let y = Math.random() * 2000 - 1000
let x = y + Math.abs(y) * (0.05 - 0.1 * Math.random())
let rnd = Math.random()
if (rnd < 0.33) {
    x = y - Math.abs(y) * 0.05 - Math.random() * 2000
}
if (rnd > 0.67) {
    x = y + Math.abs(y) * 0.05 + Math.random() * 2000
}

Build a neural network that learns to compare the sum of two numbers with a
third number. Three numbers will be fed to the network input: a, b, c.

  - The first neuron should activate if the sum of numbers a and b exceeds
    number c by more than 5%.
  - The second neuron should activate if a + b deviates from number c by no more
    than 5% in either direction.
  - The third neuron activates if the sum of numbers a and b is less than number
    c decreased by 5%.
