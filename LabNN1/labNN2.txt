Лабораторна робота з навчання нейромереж №1
Навчимо нейромережу порівнювати числа по більш складному алгоритму
Нехай вона також визначає випадок, коли числа приблизно дорівнюють один одному

Тоді на вихідному слої будуть 3 нейрони. 
Перший буде активуватися, якщо перше число перевищує друге більше ніж на 5%
Другий нейрон буде активуватися, якщо перше число знаходиться в межах відхилення у 5% від другого
І третій нейрон активується, якщо перше число менше, ніж друге з врахуванням похибки у 5%

Що для цього потрібно модифікувати в скрипті навчання?

По-перше, в мережі потрібно зробити 3 вихідних нейрони

Далі модифікуємо функцію, яка визначає правильну відповідь мережі при її навчанні
Вона має повертати 0, якщо перше число більше ніж друге, збільшене на 5%
повертати 2, якщо першее число менше ніж перше число, зменшене на 5%
і повертати 1 в усіх інших випадках
Ось що в ній має бути:

		let x = input_arr[0]
		let y = input_arr[1]
		if (x>=y+0.05*Math.abs(y)){
			return 0
		}else{
			if (x<=y-0.05*Math.abs(y)){
				return 2
			}else{
				return 1
			}			
		}

зверніть увагу, що для визначення меж ми беремо модуль від числа, щоб код працював і для від'ємних чисел

Зміни потрібні в генерації навчальної вибірки. Ми не можемо тепер обидва вхідних числа брати випадковими, і ось чому
У навчальній вибірці потрібно в рівній мірі відобразити всі ситуації, з якими мережа стикнеться
А якщо генерувати числа випадково, то випадок наближеної рівності (в межах 5%) буде дуже рідко зустрічатися

Отже, генерацію навчальних даних проведемо таким чином
Згенеруємо друге число випадково.
перше число згенеруєхмо у межах відхилення 5% від першого
Далі, у 33% випадків перегенеруємо перше число так, щоб воно було явно менше другого
У ще у 33% випадків перегенеруємо перше число так, щоб воно було явно більше другого

    	let y = Math.random()*20-10
		let x = y+Math.abs(y)*(0.05-0.1*Math.random())
		let rnd = Math.random()
		if (rnd<0.33){
			x=y-Math.abs(y)*0.05-Math.random()*20
		}
		if (rnd>0.67){
			x=y+Math.abs(y)*0.05+Math.random()*20
		}

Так само будемо поступати при генерації тестових даних. З тією лише відмінністю, що діапазон для них візьмемо від -1000 до 1000 (щоб перевірити, як мережа навчилася узагальнювати поняття порівняння)
