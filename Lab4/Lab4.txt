**Instructions for the laboratory work "Genetic Algorithms"**
In this laboratory work, we will get acquainted with bots that pass on their playing skills to their descendants, and as a result, the entire population gradually plays better.

**Step 1**
Open the Lab4 folder. Launch the index.html file in a browser and open the browser console.
At the start of the main.js script, a game world for Bachet's Game is created, in which players are allowed to take 1, 2, or 3 stones, and the one who takes the last stone wins.

In this game world, run a tournament that will include:
*   BachetBot123Best - a bot that implements the winning strategy for the game with possible moves 1, 2, 3, where the last player wins.
*   BachetBotRandomSmart - a bot that takes a random number of stones.
*   BachetBot3Smart - takes 3 if possible, otherwise 2 or 1.
*   BachetBot2Smart - takes 2 if possible, otherwise 1.
*   BachetBot1 - always takes 1 stone.
*   as well as five evolutionary bots, EvoBotSimple.

window.world.startTournamentBetweenBots([new BachetBot123Best("Best"), new BachetBotRandomSmart("RND"), new BachetBot1("Bot1"), new BachetBot2Smart("Bot2"), new BachetBot3Smart("Bot3"), new EvoBotSimple("EVO1"), new EvoBotSimple("EVO2"),new EvoBotSimple("EVO3"),new EvoBotSimple("EVO4"),new EvoBotSimple("EVO5")],1000,2,false)

Record the results of this tournament.

Keep only the 3 best evolutionary bots by executing the command in the console:
window.world.keepNoMoreThanKBestBotsOfClass(EvoBotSimple,3)
Make sure that only the EvoBots with the best results remain by displaying the list of all bots in the console:
window.world.allBots

**Step 2**
The behavior of evolutionary bots is controlled by their DNA. For EvoBotSimple, this is the rules array, where each element rules[N] indicates the number of stones the bot will take from a position with N stones.

Create 5 new evolutionary bots using the remaining ones as a basis. To do this, execute the command:

window.world.createOnlyKDescendantsOfBestBotsOfClass(EvoBotSimple,5,"A")

Examine the new bots:

window.world.allBots

Among them, there will be those created by crossing two ancestors and those created through the mutation of one ancestor.

Examine a bot created by mutation. Its name ends with _mut and contains the name of the bot used as a basis.
Determine how its DNA differs from the parent bot.

Examine a bot created by crossover. Its name contains the names of its parents.
Determine which part of its DNA was taken from which parent bot.

Run a tournament with all the bots. Since we need to use the existing bots instead of creating new ones for the tournament, do this with the command:
window.world.startTournamentBetweenBots(window.world.allBots,1000,2,false)

**Step 3**
Perform the next culling of evolutionary bots, keeping the 4 best.
window.world.keepNoMoreThanKBestBotsOfClass(EvoBotSimple,4)
See if any bots from the first generation remain among the best.

Determine the probability with which the evolutionary bots will make winning moves. To do this, execute the script:

let s=""
for (let i=0; i<100; i++){
    if (i%4!=0){
        let total = 0
        let correct = 0
        for (let k=0; k<window.world.allBots.length; k++){
            let b = window.world.allBots[k]
            if (b instanceof EvoBotSimple){
                moveOb = b.makeMoveForSituation({N:i})
                if (moveOb.n==i%4){
                    correct+=1
                }
                total+=1
            }
        }
        s+=i+"\t"+correct/total+"\n"
    }
}
console.log(s)

**Step 6**
Let's track how the results of evolutionary bots improve from generation to generation.
First, reload the page to reset the game world settings.
Create 15 evolutionary bots, one random bot, and one ideal bot:

window.world.createKNewBotsOfClass(BachetBot123Best,1,"Best")
window.world.createKNewBotsOfClass(BachetBotRandomSmart,1,"RND")
Run 250 tournaments and generation changes:

let scores=[]
for (let i=0; i<250; i++){

    window.world.createOnlyKDescendantsOfBestBotsOfClass(EvoBotSimple,30,"X"+i)

    let ar=[]

    scores.push(ar)
    window.world.keepNoMoreThanKBestBotsOfClass(EvoBotSimple,15)

console.table(scores)

Plot graphs of the bots' tournament performance.

**Step 8**
As we have seen, EvoBotSimple, based on a simple idea, demonstrates the ability to learn but takes a very long time to defeat BachetBot123Best or to win almost completely against BachetBotRandomSmart after a rule change.
Therefore, let's consider an alternative version of an evolutionary bot, EvoBotDiv.
Its DNA consists of triplets of numbers {a, b, c}. Each such triplet is interpreted as a rule: "If the current number of stones divided by a gives a remainder of b, take c stones."

Reload the browser page.
Create 5 evolutionary bots, 1 ideal bot, and 1 random bot, and run 1 tournament between them:

window.world.createKNewBotsOfClass(EvoBotDiv,5,"EVO")
window.world.createKNewBotsOfClass(BachetBot123Best,1,"Best")
window.world.createKNewBotsOfClass(BachetBotRandomSmart,1,"RND")
window.world.startTournamentBetweenBots(window.world.allBots,100,2,false)

Keep the 3 best evolutionary bots and create 5 of their descendants (note that the class name of these bots is EvoBotDiv):

window.world.keepNoMoreThanKBestBotsOfClass(EvoBotDiv,3)
window.world.createOnlyKDescendantsOfBestBotsOfClass(EvoBotDiv,5)

Examine the DNA of the descendants and determine which parts they took from which parents.
Also, find mutant bots (if there are none, create more descendants) and determine where exactly the mutation occurred in them.
