**Instructions for the laboratory work "Q-Learning"**
In this laboratory work, we will work with a bot that initially makes random moves and then learns how to play and win. We will also see how it adapts to rule changes.

**Step 1**
Open the Lab2 folder. Launch the index.html file in a browser and open the browser console.
At the start of the main.js script, a game world for Bachet's Game is created, in which players are allowed to take 1, 2, or 3 stones, and the one who takes the last stone wins.

The bots.js file contains the following bots: BachetBot1, BachetBot2Smart, BachetBot3Smart, BachetBotRandomSmart.

They take 1, 2, 3, or a random number of stones respectively, but they do not break the rules by trying to take more stones than are in the pile.

The BachetBot123Best bot has a hard-coded winning strategy for this version of Bachet's Game.

The one to compete with all these bots will be BachetLearnerBot - a bot that implements the Q-Learning self-learning method.

Set up a single-game tournament between the BachetLearnerBot and BachetBotRandomSmart bots.
To do this, enter the command in the console:
window.world.startTournamentBetweenBots([new BachetLearnerBot("Learn2"),new BachetBotRandomSmart("RND")], 1, 2, true)

Observe the tournament's progress from the console output.
Then, inspect the memory of the learning bot. To do this, enter the command in the console:
BachetLearnerBot.memory

Find the memory cells whose content does not look like {1: 3, 2: 3, 3: 3}.
What are these cells? And how does their content correlate with the moves that BachetLearnerBot made in the game?

Next, run 5 tournaments of 100 games.
Then, run 5 tournaments of 1000 games.
After that, run 5 tournaments of 10,000 games.

Create a scatter plot, setting a logarithmic scale for the x-axis.
Label the chart and its axes.

**Step 3**
Let's investigate what happens to BachetLearnerBot's memory.
Refresh the browser page to reset BachetLearnerBot's memory and run a 10-game tournament against BachetBotRandomSmart.

let s=""
for (let i=0; i<BachetLearnerBot.memory.length; i++){
    if (i%4!=0){

    }
