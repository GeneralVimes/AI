**Step 3**
BachetBotRandomSmart only makes random moves from the range of 1, 2, 3. It is also unaware that the game rules can change.
Create a bot, UniversalRandomBot, that will make moves that do not violate the rules, but takes them from the current game's rules.
The move function for this bot will look like this:

makeMoveForSituation(gameDataOb){
    var selectedMoveVal = -1;
    //iterate through all allowed moves and choose a random one
    for (var i=0; i<this.currentGameRulesObject.allowedMoves.length; i++){
        var moveVal = this.currentGameRulesObject.allowedMoves[i];
        var newPos = gameDataOb.N-moveVal;	
        if (newPos>=0){
            if (selectedMoveVal==-1 || Math.random()<1/(i+1)){
                selectedMoveVal = moveVal;
            }
        }
    }
    return {n:selectedMoveVal}
}
